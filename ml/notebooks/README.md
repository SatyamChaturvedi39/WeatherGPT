 # ML Notebooks

Production and benchmark Jupyter notebooks for WeatherGPT exploratory data analysis, leak-free feature engineering, multi-horizon point & quantile regression, probabilistic precipitation classification, anomaly detection, and TreeSHAP explainability.

## Active Notebooks

- **`WeatherGPT_ML_Pipeline_and_Model_Comparison.ipynb`**: Complete end-to-end ML pipeline reproducing all active WeatherGPT production models alongside 6 competing benchmark architectures (Ridge, HistGradientBoosting, Random Forest, Extra Trees, MLP, PyTorch Multi-Horizon LSTM) under strict 24-hour embargo chronological holdout evaluation.
