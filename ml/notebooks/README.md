# ML Notebooks

Jupyter notebooks for EDA, training, and evaluation.
Run these in Google Colab (free T4 GPU) or locally.

## Notebook Order

1. `01_eda.ipynb` — Exploratory Data Analysis
2. `02_feature_engineering.ipynb` — Feature engineering experiments
3. `03_model_training.ipynb` — Train & compare XGBoost, LSTM
4. `04_evaluation.ipynb` — Full evaluation report with metrics
